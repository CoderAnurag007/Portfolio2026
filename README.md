# Anurag Singh — Portfolio

Premium personal portfolio for an experienced software engineer transitioning into AI/ML engineering.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- next-themes (light / dark)

## Getting started

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Edit structured content in `src/data/`:

- `site.ts` — name, links, SEO, navigation
- `experience.ts` — professional timeline
- `projects.ts` — featured projects
- `skills.ts` — skill groups
- `journey.ts` — AI roadmap + learning now
- `impact.ts` — engineering metrics
- `testimonials.ts` — quotes + philosophy

Assets live in `public/images` and `public/resume`.

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint
